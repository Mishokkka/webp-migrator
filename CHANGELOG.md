# Changelog

## 0.2.1

- Исправлено чтение галочек перед сканированием: их значения теперь снимаются до busy-render ApplicationV2.
- Выбор областей синхронизируется с внутренним состоянием сразу при изменении checkbox.
- После сканирования интерфейс сохраняет фактически выбранные пользователем области, а не возвращается к значениям по умолчанию.
- Добавлен устойчивый fallback для чтения опций, если часть формы временно отсутствует при перерисовке.

## 0.2.0

- Переписан интерфейс на штатные `ApplicationV2` actions без ручного навешивания обработчиков кнопок.
- Исправлен перехват асинхронных ошибок и зависание `busy` после rejected Promise.
- Manifest получил `schemaVersion` и случайный `manifestId`.
- Conversion report больше не может передавать Foundry поля и UUID для изменения. Ссылки берутся только из текущего manifest.
- Проверяются `manifestId`, `worldId`, `oldPath` и `newPath`.
- Перед изменением проверяется текущее значение поля. Устаревшие ссылки не перезаписываются.
- После каждого `Document.update` выполняется проверка результата.
- Добавлен откат путей текущего запуска.
- Добавлено временное снятие блокировки world compendiums с восстановлением исходной блокировки.
- Добавлен GM-only guard для окна и публичного API.
- Исправлен `scanToManifest`: сканер больше не зависит от DOM приложения.
- Вместо жесткого списка Actor/Item/Tile используется общий рекурсивный сканер документов и embedded documents.
- Добавлено покрытие Scenes, Journals, RollTables, Cards, Macros, Users, ChatMessages, Playlists, Combats, Folders, flags и system data.
- Добавлен поиск PNG внутри HTML, Markdown, macro command и строковых flags/system полей.
- Добавлено объединение путей с query/hash по одному физическому PNG.
- Добавлена поддержка wildcard `*` и `?` во внешнем конвертере.
- `cwebp` теперь пишет во временный файл и только после проверки заменяет целевой WEBP.
- Проверяется RIFF/WEBP header существующих и новых файлов.
- Cleanup не удаляет PNG при отсутствующем или поврежденном WEBP.
- APNG определяется и пропускается, чтобы не потерять анимацию.
- Ошибки конвертации/cleanup дают ненулевой exit code.
- Добавлены понятные проверки `--data` и `--cwebp`, включая частую ошибку с передачей папки `bin` вместо `cwebp.exe`.
- Добавлены LICENSE и автоматические тесты чистых функций.
