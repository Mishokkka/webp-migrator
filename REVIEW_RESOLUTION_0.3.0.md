# Сводный разбор ревью и исправлений FBL WebP Migrator 0.3.0

Дата: 2026-08-06  
Целевая среда: Foundry VTT 13.351  
Исходная версия: 0.2.1  
Исправленная версия: 0.3.0

## Источники

Список сформирован дедупликацией трех независимых наборов замечаний:

1. глубокого ревью исходного архива 0.2.1;
2. дополнительного независимого ревью `REVIEW(1).md`;
3. комментариев CodeRabbit в pull request №1.

Повторяющиеся пункты объединены. Предположения, которые нельзя надежно проверить вне живого Foundry, отделены от воспроизводимых дефектов.

## Итог

В 0.3.0 исправлены все воспроизведенные дефекты безопасности, целостности данных и доверия к импортируемым отчетам. Разрушительный cleanup заменен на проверяемый карантин по умолчанию. Добавлены функциональные тесты внешнего CLI и новые тесты миграции Foundry.

Часть замечаний являлась не ошибками кода, а ограничениями Foundry или запросами на расширение продукта. Они не маскируются: ограничения явно показаны в UI и README.

## Дополнительные защитные изменения

В процессе исправления обнаружены и закрыты два дополнительных trust-boundary дефекта, отсутствовавшие в исходных отчетах:

1. импортируемый manifest теперь не может подменить `oldValue/newValue` при сохранении разрешенных физических путей;
2. вручную сконструированный in-memory `assume-existing` object не принимается mutation API без непереносимого внутреннего маркера.

## Проверка

Команда:

```bash
npm run check
```

проверяет:

- все Node tests;
- синтаксис `tools/convert-cwebp.js`;
- синтаксис `scripts/main.mjs`.

В тесты входят воспроизведения критических сценариев: trailing whitespace, APNG + existing WEBP, fake WEBP, strict booleans, wildcard `?`, symlink escape, failed overwrite, forged reports, concurrent document changes, cleanup hash mismatch, quarantine и restore.
